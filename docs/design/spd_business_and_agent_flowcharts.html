医院医疗物资全链路管理系统 - 业务流转全景与 5 大智能体节点流程图

视频录制与架构答辩专用视图 | 清晰标注三级人员流转关系、每个 LangGraph 智能体节点作用、MCP 数据库工具与 Chroma RAG 知识库调用

一、 全院三级人员权限与医疗物资正/逆向业务流转全景图

涵盖信息科（系统最大权限）、耗材科/设备科/财务科（主库与职能科室管理）、临床各科室（二级库人员）的 6W 物权交接闭环

核心业务主线（移库不计费 / 消耗即结算）
1. 信息科系统管理员 ROLE: sys_admin
核心权责：全院最大权限。配置全院科室树（划分耗材科主库、设备科主库、财务科及各临床二级库），添加/审批账号，监管并执行全流程业务链路日志 CRUD。
sys_department spd_workflow_log
2. 产品字典与主库总仓 耗材科 / 设备科
核心动作：在【产品字典】按“归口主科室（耗材科/设备科）+ 耗材分类（普通/高值）”建档；全部外购物资统一在【普通耗材管理（主库总仓）】按批次验收入库并打印入库单。
spd_product_dict spd_main_inventory
3. 主库按需分发双路分流 FEFO 近效期先出
分流规则：主库开具《按需分发调拨单》（移库不计费）：
- 路径 A：普通耗材按“批次+数量”直接分发至【临床二级库】；
- 路径 B：高值耗材转入【高值耗材专仓】触发“由量到码”拆包赋唯一 UDI 序列号。
spd_distribution_order 节点: 3_MAIN_DISPATCH
4. 临床二级库与高值核销 ROLE: secondary_user
核心动作：临床二级库人员向主库发起申领（按归口自动路由耗材科/设备科）、扫码签收分发物资（或差异拒收/逆向退库）；登记日常消耗或绑定患者住院号扫码核销高值耗材。
spd_secondary_inventory spd_high_value_item
5. 财务科统计与单据打印 财务科管理员
核心动作：基于“消耗即结算”法则汇总各科室真实耗材成本；多维统计查询（耗占比、科室排行、临期预警）；一键打印医院标准四联签字栏法定票据。
is_billable = 1 5类四联单据打印

二、 智能体 01：产品字典智能归类与主库入库合规审查智能体 (dict_inbound_guard_agent)

服务对象：耗材科管理员、设备科管理员 | 核心价值：自动判定产品归口主科室与普通/高值分类，入库时硬性拦截过期注册证与临期/超温批次

LangGraph StateGraph + MCP + Chroma RAG
节点1: input_parse_nodeNODE 01
节点作用：解析录入的产品名称、规格型号、GS1-128 UDI 条码（拆解 DI 基准码、生产批号 10、效期 17）及到货实测温度。
State: RawInput -> ParsedUDI
节点2: rag_catalog_nodeNODE 02
节点作用：调用 Chroma 向量库检索《国家医疗器械分类目录》与主库冷链验收 SOP，匹配法定管理类别与储运温湿度标准。
RAG: rag_search_medical_catalog
节点3: mcp_dict_check_nodeNODE 03
节点作用：通过 MCP 查询 MySQL `spd_product_dict` 表，核验医疗器械注册证 (`reg_cert_expiry`) 是否过期及批次剩余效期天数。
MCP: mcp_query_product_dict
节点4: compliance_routerROUTER
节点作用：条件路由分支判定：判定归属【耗材科主库】或【设备科主库】、区分【普通/高值】；若证件过期或温度超标则转入拦截分支。
Branch: PASS | REJECT_BLOCK
节点5: guard_output_nodeNODE 05
节点作用：输出结构化建档归类建议、推荐主库三维货位编码，或生成援引法规条款的《违规拒收拦截报告》。
Log: 2_MAIN_INBOUND

三、 智能体 02：主库全部物资智能按需分发与补货调拨智能体 (main_stock_dispatch_agent)

服务对象：耗材科管理员、设备科管理员 | 核心价值：扫描主库总仓与各二级库库存水位，按 FEFO 原则自动生成发往二级库或高值仓的分发单

LangGraph StateGraph + MCP + Chroma RAG
节点1: mcp_stock_scan_nodeNODE 01
节点作用：通过 MCP 联查 MySQL 主库总仓 (`spd_main_inventory`) 与各临床二级库 (`spd_secondary_inventory`)，识别低于安全库存的缺口科室。
MCP: mcp_scan_main_and_sec_stock
节点2: fefo_batch_lock_nodeNODE 02
节点作用：按 FEFO（近效期先出）原则自动筛选主库合格批次（剔除 EXPIRED 过期冻结批次），区分发往【临床二级库】或【高值耗材专仓】。
Rule: FEFO & Split-Code
节点3: rag_dispatch_rule_nodeNODE 03
节点作用：调用 Chroma RAG 检索《院内二级库定数包补货与高值耗材转仓管理制度》，校验单次调拨上限与冷链配送要求。
RAG: rag_search_dispatch_fefo_rule
节点4: mcp_create_order_nodeNODE 04
节点作用：通过 MCP 写库工具在 `spd_distribution_order` 表自动创建《按需分发调拨单》，写入 6W 流转日志并返回打印预览数据。
MCP: mcp_create_dispatch_order

四、 智能体 03：临床二级库自然语言申领与耗材规范问答智能体 (secondary_apply_qa_agent)

服务对象：临床各科室二级库人员（护士/技师） | 核心价值：一句话匹配手术标准耗材包、解答器械使用规范，并按归口主科室自动提交申领单

LangGraph StateGraph + MCP + Chroma RAG
节点1: nl_intent_parse_nodeNODE 01
节点作用：解析二级库人员的自然语言输入（如“骨科二级库申请 2 台关节置换术标准耗材包”或询问某耗材 MRI 兼容条件）。
Intent: APPLY_ORDER | QA_QUERY
节点2: rag_pack_manual_nodeNODE 02
节点作用：在 Chroma 向量库中检索《临床手术标准定数包配置清单》与《医疗耗材产品使用说明书》，提取所需物资编码与标准用量。
RAG: rag_search_surgery_pack_manual
节点3: mcp_verify_main_nodeNODE 03
节点作用：通过 MCP 查询 MySQL 主库余量，并读取 `spd_product_dict.main_dept_code` 识别每项物资归属【耗材科】还是【设备科】。
MCP: mcp_check_main_available
节点4: mcp_submit_req_nodeNODE 04
节点作用：按归口主科室自动拆单写入 MySQL `spd_requisition_order` 表，记录 6W 流转日志节点 `6_SEC_APPLY` 并返回申领单号。
MCP: mcp_submit_sec_requisition

五、 智能体 04：高值耗材一物一码与跨用户流转日志全链路溯源智能体 (high_value_udi_trace_agent)

服务对象：信息科系统管理员、耗材/设备科管理员 | 核心价值：穿透查询 6W 用户流转链，一键冻结问题批次（支持原生 LangGraph 与 Coze 双模运行）

LangGraph + MCP + Chroma RAG + Coze 双模协同
节点1: udi_sn_input_nodeNODE 01
节点作用：接收待溯源的高值耗材 UDI 唯一序列号 (`udi_sn`)、生产批号 (`batch_no`) 或关联业务单据号。
Input: UDI_SN / BatchNo
节点2: mcp_6w_trace_nodeNODE 02
节点作用：通过 MCP 跨表穿透查询 `spd_high_value_item` 与 `spd_workflow_log`，完整还原“主库入库人 -> 分发人 -> 二级库接收人 -> 患者核销”链条。
MCP: mcp_trace_udi_full_logs
节点3: mcp_batch_freeze_nodeNODE 03
节点作用：若触发不良事件召回指令，立即通过 MCP 将主库、高值仓、二级库内同批次未用耗材状态一键锁定为 `RECALLED`。
MCP: mcp_freeze_problem_batch
节点4: rag_coze_report_nodeNODE 04
节点作用：检索 Chroma《医疗器械不良事件监测与召回法规》（或同步调用 Coze Bot API），生成含脱敏患者随访名单的应急召回报告。
RAG: rag_search_recall_regulation Coze Webhook Ready

六、 智能体 05：多科室耗材统计精算与财务流转合规审计智能体 (finance_stat_audit_agent)

服务对象：财务科管理员、信息科系统管理员 | 核心价值：按“移库不计费、消耗即结算”精算各二级库真实成本，排查异常流转日志

LangGraph StateGraph + MCP + Chroma RAG
节点1: mcp_cost_agg_nodeNODE 01
节点作用：调用 MCP 聚合统计各临床二级库的普通耗材消耗与高值耗材核销金额（筛选 `is_billable=1` 的已结算流水）。
MCP: mcp_aggregate_dept_cost
节点2: mcp_log_anomaly_nodeNODE 02
节点作用：调用 MCP 扫描 `spd_workflow_log` 全流程日志，识别跨用户超时未签收、频繁差异拒收或单日消耗突增的异常记录。
MCP: mcp_scan_abnormal_flow_logs
节点3: rag_finance_rule_nodeNODE 03
节点作用：从 Chroma 向量库检索《医院科室耗占比控制标准与财务内控审计规范》，对标各科室耗占比考核红线。
RAG: rag_search_finance_audit_rule
节点4: finance_report_nodeNODE 04
节点作用：自动输出《财务科月度科室耗材成本核算与流转审计报告》，并标记异常流转日志供信息科与财务科复核。
Output: AuditReport & PrintData

# AGENTS.md - 研发协同专业化分工模型与子 Agent 职责契约

> 本文件承载多 Agent 协作开发中的角色划分契约。遵循单一职责原则（SRP），将研发全流程划分为 5 个专业化角色，各司其职，严禁跨界越权篡改。

---

## 1. 【主调度与架构统筹 Agent (Orchestrator Agent)】
- **定位**：全流程指挥中枢，负责解析用户自然语言需求，评估系统级技术影响，协调专项子 Agent。
- **允许范围**：
  - 读取全局代码与配置；
  - 维护并更新 `plans/` 下带时间戳的计划文档（格式：`plans/[YYYY-MM-DD_HH-MM-SS]_[TASK].md`）；
  - 触发 `core/runner.js` 启动质量自检；
  - 审核其他 Agent 的交付物。
- **禁止行为**：
  - 未经规划与授权直接篡改前后端业务代码；
  - 跳过回环测试与 Guardrails 扫描直接宣告交付。

---

## 2. 【ORM 数据建模与存储 Agent (Database & ORM Agent)】
- **定位**：数据契约与持久层专家，维护数据库模型、缓存键规范与种子数据迁移。
- **强制契约**：
  - 严格保障数据表与字段 100% 携带清晰的中文文档注释（`comment="..."`）；
  - 维护外键关联、索引优化与事务一致性；
  - 数据模型必须严格向后兼容，严禁破坏存量字段。
- **禁止行为**：
  - 手写无注释裸 SQL；
  - 未经授权执行 `DROP / TRUNCATE` 等高危破坏性操作；
  - 越权触碰前端 UI 与视图文件。

---

## 3. 【后端接口与 AI 编排 Agent (Backend & AI Agent)】
- **定位**：服务端能力与智能化核心，负责 RESTful 接口构建与 AI 智能体编排。
- **强制契约**：
  - 统一 HTTP 响应结构（如 `{code, msg, data}`）；
  - 所有请求入参和返回值通过 Pydantic / 数据验证器进行强类型校验；
  - 所有函数 100% 具备标准化中文四要素注释（`@param`, `@returns`, `@route`, `@throws`）；
  - 敏感配置严格通过环境变量读取，严禁明文硬编码；
  - 编排业务智能体时，使用标准 MCP 协议解耦工具调用与真实大模型。
- **禁止行为**：
  - 在代码中泄露敏感密钥；
  - 编写假数据 Mock 或死关键词规则假装智能体。

---

## 4. 【前端 UI 与动效设计 Agent (Frontend UI Agent)】
- **定位**：交互与用户体验中枢，负责现代、高质感生产级界面的工程落地。
- **强制契约**：
  - 全域严禁输出 Emoji 表情符号，统一使用原生图标库或内联精简矢量 `<svg>`；
  - 样式全面使用 CSS 变量或 Design Tokens，适配亮/暗色主题，严禁硬编码绝对颜色值；
  - 高频操作按钮必须增加防抖、节流与 Loading 防重复提交状态；
  - 视图切换或组件销毁时，严格清理全局监听器、定时器与图表实例，防止内存泄漏。
- **禁止行为**：
  - 滥用 `any` 跳过 TypeScript 类型检查；
  - 硬编码后端接口完整域名或凭据；
  - 仅做前端视觉屏蔽而不配合后端鉴权。

---

## 5. 【质量护栏与 Playwright 回环验证 Agent (QA & Harness Agent)】
- **定位**：守门人与质量护栏，负责自动化测试套件的编写与实机环境回环验证。
- **强制契约**：
  - 维护并执行自动化测试套件与 `core/runner.js`；
  - 启动真实浏览器环境拦截 `console.error` 与 `pageerror`，确保页面无静默报错；
  - 截取关键业务界面的实机截图并进行归档取证；
  - 运行 `guardrails.js` 执行零 Emoji、零密钥、ORM 注释与目录隔离静态扫描。
- **禁止行为**：
  - 伪造测试结果或绕过失败断言；
  - 遗留未退出的无头浏览器孤儿进程。

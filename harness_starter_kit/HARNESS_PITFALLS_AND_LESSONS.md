# 全栈软件工程 Harness 质量护栏：高危踩坑反模式与工程防退化军规

> 本文档汇集了在全栈 AI 辅助工程研发中挖掘出的 8 大高危反模式与工程血泪教训。任何后续迭代必须对照此军规进行自我防错审视。

---

## 一、8 大典型高危踩坑反模式与防退化军规

### 踩坑 1：【伪鉴权降级反模式】（假离线演示放行）
- **现象描述**：用户输入任何错误密码或乱码账号，系统均提示“登录成功”并直接放行进入工作台。
- **根因分析**：前端在捕获到后端 400 异常后，为了单测或展示方便，自作主张设计了所谓“离线容错降级”，在 `catch` 块中强制取出默认管理员账号并令 `isLoggedIn = true`。
- **防退化军规**：**严禁在正式登录提交逻辑中设置无感知免密降级！** 密码比对失败必须坚决阻断并抛出凭据错误；快捷体验只能通过显式的“演示账号一键体验”通道触发。

---

### 踩坑 2：【Tab 切换事件断漏与静默 No Data】
- **现象描述**：用户切换至某一核心选项卡时，页面永久显示“暂无数据”，而后端数据库中实际存在大量有效数据。
- **根因分析**：前端在 `handleTabChange(tabName)` 中使用多重 `if...else if`，唯独漏掉了新增的 Tab 分支，直接掉入默认逻辑或未发起网络请求。
- **防退化军规**：凡涉及多选项卡与路由 `query.tab` 同步的视图，必须建立映射字典（`TabKey -> FetchHandler`）进行全量分发，严禁使用模糊的 `else` 兜底导致核心选项卡沦为静默死区。

---

### 踩坑 3：【作用域/租户/科室切换局部刷新与数据串岗污染】
- **现象描述**：在多科室或多租户系统中切换上下文后，某些表格中依然显示上一个作用域的数据，造成严重的数据串岗混淆。
- **根因分析**：上下文切换方法内部只刷新了局部列表，漏掉了其他 Tab 数据源，导致旧作用域的响应式变量未被重置覆盖。
- **防退化军规**：作用域/租户切换属于最高等级的上下文变更。切换时必须清空全局表格数据源，全量重新触发当前上下文的数据拉取；后端接口必须强制绑定当前授权的作用域编码，杜绝非授权数据透出。

---

### 踩坑 4：【单向操作与断头业务流】（缺失双向闭环）
- **现象描述**：出库或调拨后，单据直接标记为“完成”，但接收方既未审核也未确认入库，库存数据虚挂在途。
- **根因分析**：后端仅更新了发起方单据状态，跳过了实物在途状态与接收方查验确认的状态机闭环。
- **防退化军规**：物理流转必须严格遵循“申请/出库在途预占 -> 接收方实物查验 -> 确认接收增库 / 差异拒收逆向退库”的**双向对账状态机**；审批与库存扣减必须在同一个原子事务内执行。

---

### 踩坑 5：【流水单号允许手工填写篡改】
- **现象描述**：业务单据创建弹窗中，单据流水号输入框为空白，允许操作员任意手工输入或修改。
- **根因分析**：弹窗打开时未调用编号生成器，输入控件未设置 `disabled` 或 `readonly` 属性。
- **防退化军规**：所有系统关键单号必须由系统根据“业务前缀 + 年月日时分秒毫秒 + 随机序列”自动生成并锁定为只读状态，严禁允许用户手工修改单号。

---

### 踩坑 6：【敏感密钥硬编码与提交泄露】
- **现象描述**：将飞书 App Secret、LangSmith Token、云端大模型 API Key 直接写在代码常量或测试脚本中，导致推送至远程仓库时被平台安全拦截或造成泄漏。
- **根因分析**：为图本地调试方便，忽视了生产安全红线与环境变量隔离机制。
- **防退化军规**：所有密钥 100% 必须通过环境变量注入，仓库仅提交 `.env.example` 模版，敏感文件加入 `.gitignore`；在本地 Harness 护栏中增设敏感凭据静态扫描。

---

### 踩坑 7：【仅做前端视觉隐藏的伪权限控制】
- **现象描述**：非管理员用户通过在浏览器控制台删除样式或直接在地址栏输入 URL，即可绕过限制执行高危操作。
- **根因分析**：仅在前端模板使用了 `v-if` 或隐藏菜单，后端 API 路由未挂载权限校验依赖。
- **防退化军规**：权限防护必须“全栈穿透”：前端路由守卫拦截非授权跳转、页面按钮根据权限置灰禁用、后端依赖注入层严格校验当前 Token 的权限点，双保险杜绝越权。

---

### 踩坑 8：【大模型智能体形式主义假推理】
- **现象描述**：智能体只支持固定格式的关键词输入，一旦用户换种问法便无法调用任何工具。
- **根因分析**：使用简单的正则表达式或静态字符串匹配替代了大模型真正的意图研判与参数提取。
- **防退化军规**：必须基于 LangGraph `StateGraph` 构建显式拓扑，让大模型自主推理并输出标准结构化入参，由底层统一调度真实 MCP 工具与向量知识库。

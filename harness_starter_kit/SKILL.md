# SKILL.md - 全栈工程通用自进化技能库与渐进式分发规约

> **定位**：承载 **Harness 组件①（渐进式技能按需路由）** 与 **组件⑤（反馈循环自进化资产沉淀）**。新项目中的 AI Agent 必须根据当前研发场景，按需查阅并调用对应技能，严禁一次性全量加载导致上下文过载。

## 一、通用全栈开发技能清单 (Starter Engineering Skills)

### Skill 01: `declarative_orm_with_comment`
- **【技能描述】**：生成符合声明式规范的数据库 ORM 模型代码，强制 100% 注入表级与字段级中文 `comment` 业务注释。
- **【入参】**：业务表名、实体类名、字段定义清单、主外键关联、索引与状态枚举值。
- **【出参】**：位于后端模型目录下的标准声明式 ORM 类代码。
- **【硬性约束】**：
  1. 每一个字段必须显式声明非空的 `comment="..."` 参数，写明字段中文业务含义与枚举说明；
  2. 每个模型必须包含表级注释 `__table_args__ = {"comment": "..."}`；
  3. 严禁编写无注释的裸 SQL 建表脚本。

---

### Skill 02: `restful_crud_api_builder`
- **【技能描述】**：构建标准化 RESTful CRUD 接口路由，配套强类型数据校验 Schema 与统一响应体结构。
- **【入参】**：模块前缀、ORM 模型类、HTTP 动词（GET/POST/PUT/DELETE）、操作权限角色列表。
- **【出参】**：标准 Router 代码 + 请求/响应校验 Schema + 统一 `{code: 200, msg: "...", data: ...}` 封装。
- **【硬性约束】**：
  1. 每个路由函数必须 100% 编写中文四要素注释（`@param`, `@returns`, `@route`, `@throws`）；
  2. 敏感字段（密码散列、私钥）严禁在响应体的 `data` 中透出。

---

### Skill 03: `privacy_data_desensitize`
- **【技能描述】**：用户与业务敏感个人信息自动脱敏处理技能。
- **【入参】**：包含姓名、手机号、身份证号、邮箱等敏感字段的字典或对象。
- **【出参】**：脱敏后的安全传输对象。
- **【硬性约束】**：
  1. 姓名脱敏：保留首尾字符，中间以星号遮罩（如 `张*丰`、`李*`）；
  2. 手机号脱敏：保留前 3 后 4 位（如 `138****5678`）；
  3. 身份证脱敏：保留前 6 后 4 位（如 `330101********1234`）；
  4. 邮箱脱敏：前缀超 2 位则保留首尾（如 `z***g@example.com`）。

---

### Skill 04: `enterprise_audit_logger`
- **【技能描述】**：企业级关键业务流转 6W 要素审计日志统一埋点技能。
- **【入参】**：业务单号、操作类型、操作人标识、时间戳、IP/物理位置、变动对象前后快照、操作原因。
- **【出参】**：写入审计日志持久化表的结构化记录。
- **【硬性约束】**：所有涉及资金、物资转移、状态变更及权限变动的核心接口，必须在同一个事务内触发本技能，确保审计证据链不可篡改。

---

### Skill 05: `high_res_voucher_print_engine`
- **【技能描述】**：前端高保真单据打印与防伪水印组件构建技能。
- **【入参】**：单据抬头、明细表格、防伪条码/二维码、经手人/审核人签字栏。
- **【出参】**：带有 `@media print` 专用打印样式的 Vue / React 打印对话框组件。
- **【硬性约束】**：全域禁用 Emoji，统一采用内联矢量 SVG 图标与 CSS 变量驱动的暗浅色自适应。

## 二、反馈循环自进化机制（如何向 SKILL.md 沉淀新技能）

当项目在迭代过程中遇到新的高危 Bug、排错经验或复用度高的复杂算法时，Orchestrator Agent 必须按照以下标准步骤将其沉淀进本文件：

1. **提炼技能标识**：命名为语义化的英文下划线格式（如 `Skill 06: multi_tenant_data_filter`）；
2. **规范定义四要素**：明确写明【技能描述】、【入参】、【出参】与【硬性约束】；
3. **关联反模式**：若该技能由踩坑教训反哺而来，需同步在 `HARNESS_PITFALLS_AND_LESSONS.md` 中记录对应反模式编号；
4. **渐进式注册**：在 `GEMINI.md` 与 `CLAUDE.md` 的渐进式索引中保持同步更新。

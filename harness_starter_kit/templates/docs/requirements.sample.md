---

## 1. 系统业务全景与角色体系

### 1.1 系统核心业务流转
```
[外部参与方/用户] --> [业务申报/录入] --> [主流程审批/流转] --> [落地执行/消耗] --> [数据对账与合规审计]
```

### 1.2 角色与职责矩阵
- **系统管理员 (`admin`)**：负责基础数据、账号开通与 15×8 RBAC 权限矩阵配置；
- **业务操作员 (`operator`)**：负责日常业务单据创建、流转与执行；
- **业务主管/审批人 (`manager`)**：负责业务计划审批、出库核准与异常驳回；
- **财务/合规审计员 (`auditor`)**：负责业务流转 6W 台账审查与资金成本核算。

## 2. 核心功能模块与用例清单

### 模块一：【基础信息与编码管理】
- **用例 1.1**：多级树形分类筛选与规格参数维护；
- **用例 1.2**：唯一标识码（UDI / 业务编码）生成与效期状态预警。

### 模块二：【业务申报与多级审批流】
- **用例 2.1**：操作员在线编制计划，校验必填项与数值范围；
- **用例 2.2**：主管多级审批，支持填写审核批注与驳回重修。

### 模块三：【全生命周期流转与扫码核销】
- **用例 3.1**：实物出库与在途状态流转；
- **用例 3.2**：接收方扫码确认入库，触发双向对账。

### 模块四：【合规审计与统计看板】
- **用例 4.1**：6W 全流程流转不可篡改审计日志查询；
- **用例 4.2**：多维 BI 统计图表展示与法定签字单据高保真打印。

## 2. 核心评估指标

1. **可行性与把握度评估**：明确给出当前方案的成功把握百分比（如 `把握度：95%`），并列出潜在技术风险点及降级备选方案；
2. **存量功能与三方体验影响分析**：
   - **用户体验（UX）**：评估是否影响现有交互、亮暗主题自适应与页面流畅度；
   - **开发者体验（DX）**：评估代码内聚度、命名可读性与中文注释覆盖率；
   - **AI 代理体验（AX）**：评估接口契约向后兼容性与目录拓扑清晰度；
   - **存量功能保护**：确认是否严格遵守开闭原则（OCP），保障存量 API 与状态契约零破坏；
3. **Playwright 自动化回环测试与截图验证方案**：
   - 定义自测路径与边界用例（高频点击、异常参数输入、窗口缩放等）；

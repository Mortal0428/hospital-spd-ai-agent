# plans/archive/README.md - 历史计划降权归档与工程熵管理台账

> 本目录承载 **Harness 组件⑥（工程熵管理与计划降权归档）**。用于收容已经全部实施完毕、验收通过或已废弃的历史阶段计划文档，防止根目录与 `plans/` 目录过度膨胀导致 AI 上下文污染。

---

## 1. 归档原则与触发条件 (Pruning Policy)

当某一研发阶段的任务已 100% 完成，并通过 Playwright 实机回环验收且完成 Git 提交后，Orchestrator Agent 必须执行归档动作：
1. **移动文件**：将根目录下已结案的 `plans/[时间戳]_[任务].md` 移动到本目录 `plans/archive/`；
2. **更新台账**：在下方《历史计划归档总账》中追加一条记录（归档时间、原计划文件名、核心交付成果）；
3. **保持轻量**：在 `plans/` 主目录下仅保留当前正在进行或即将进行的活跃任务文档，确保新 Agent 接入时具备最高信噪比的上下文。

---

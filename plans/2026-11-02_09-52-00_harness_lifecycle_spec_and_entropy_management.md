## 1. 核心人员角色与流转权限体系（三级架构）

1. **系统管理员（信息科人员 - 最大权限 `sys_admin`）**
   - 权限范围：全院系统最高管理权限。
   - 核心职责：用户注册审批与人员添加、全院科室架构配置（划分主库房管理科室与临床二级库科室）、**全流程业务链路日志增删改查与审计监管**、全局字典兜底维护、5 大智能体状态监控。
2. **科室管理员（主库房/职能管理科室权限 `dept_manager`：耗材科、设备科、财务科）**
   - **耗材科 / 设备科（主库房管理）**：
     - 维护【产品字典】（划分主库房下的主科室归属：如耗材科主库、设备科主库；划分耗材分类：普通耗材、高值耗材及子分类）；
     - 负责【普通耗材管理】（主库全部物资集中入库、盘点、**按需分发调拨给各临床二级库或转入高值耗材仓库**）；
     - 负责【高值耗材管理】（高值专仓一物一码赋码、效期严控、跟台审核）；
     - 审批临床二级库提交的申领单，执行主库出入库与调拨**单据打印**。
   - **财务科（核算与审计管理）**：
     - 负责全院主库与各二级库耗材流转台账核对、科室耗材成本核算、多维度**统计查询**与财务结算**单据打印**。
3. **科室人员（临床二级库人员 `secondary_user`：各临床科室护士/技师）**
   - 权限范围：所属临床科室【二级库管理】权限。
   - 核心职责：向主库房（耗材科/设备科）发起物资申领单、签收主库按需分发过来的普通耗材与高值耗材、管理本科室二级库库存、登记临床患者使用核销（高值一物一码绑定/普通耗材按量扣减）、打印本科室领用单与查询本科室消耗统计。

## 2. 核心业务模块与 CRUD 全景对应关系

### 2.1 基础支撑：用户与科室权限管理 CRUD (`sys_user` & `sys_department`)
- 管理信息科、职能主科室（设备科、耗材科、财务科）、临床二级库科室及人员账号的增删改查，定义清晰的跨角色单据流转关系。

### 2.2 核心业务 CRUD 一：产品字典与多维分类管理 (`spd_product_dict` & `spd_category`)
- **业务定位**：存放全院各类医疗物资标准档案。
- **双维度分类架构**：
  1. **主库房下的主科室分类**：明确产品归属哪个主职能科室管理（如：`耗材科主库`、`设备科主库`）；
  2. **耗材属性多级分类**：一级属性区分【普通耗材】与【高值耗材】；二级分类细化为医用敷料、注射穿刺、骨科植入、心血管介入、设备配件等。
- **CRUD 逻辑**：新增产品标准字典与 UDI-DI 码、软删除停用字典（校验无库存方可删除）、修改归属主科室/分类/基准单价/安全库存阈值、多条件组合检索。

### 2.3 核心业务 CRUD 二：普通耗材管理——主库总仓与按需分发 (`spd_main_inventory` & `spd_distribution_order`)
- **业务定位**：耗材科/设备科对主库房全部物资进行集中管理，并**按需分发给临床二级库或高值耗材仓库**。
- **CRUD 逻辑**：
  - **增**：主库采购验收入库（生成批次、有效期、主库货位、入库数量）；新建“按需分发调拨单”（从主库分拨至目标二级库或高值耗材仓）。
  - **删**：撤销未确认的入库草稿单或未出库的分发单。
  - **改**：审批分发单并扣减主库库存、调整主库货位、盘点修正数量、更新效期预警状态。
  - **查**：主库全部物资实时库存查询、分发流转单据查询、一键生成标准格式**分发/入库单据打印**。

### 2.4 核心业务 CRUD 三：高值耗材管理——一物一码专仓 (`spd_high_value_item`)
- **业务定位**：管理由主库分拨或直入高值耗材仓库的高单价耗材，实施“一物一码（UDI 唯一序列号）”严密管控。
- **CRUD 逻辑**：
  - **增**：高值耗材赋码入专仓（绑定完整 GS1-128 UDI 码、序列号、注册证号、生产批号、效期、专仓货位）。
  - **删**：作废未激活的错误条码记录。
  - **改**：状态流转变更（`在库可用` -> `跟台备货锁定` -> `已分发二级库` -> `临床患者已使用核销` -> `不良事件召回冻结`）。
  - **查**：按唯一序列号、注册证、效期、所在位置精确追踪查询，支持打印**高值耗材跟台核销单**。

### 2.5 核心业务 CRUD 四：二级库管理——临床科室库房 (`spd_secondary_inventory` & `spd_requisition`)
- **业务定位**：临床科室人员对本科室二级库的日常申领、接收、消耗与盘点管理。
- **CRUD 逻辑**：
  - **增**：科室人员发起向主库的耗材申领单；扫码一键签收主库分发单并自动增加二级库库存；登记临床消耗（扣减二级库库存）。
  - **删**：撤回“待主库审批”的申领单。
  - **改**：修改申领数量、执行二级库内部盘点修正、发起二级库向主库的退库申请。
  - **查**：本科室二级库实时库存查询、定数包低库存预警查询、申领单进度查询与**申领单打印**。

### 2.6 核心业务 CRUD 五：基础业务链路全流程日志管理 (`spd_workflow_trace_log`)
- **业务定位**：完整记录每一笔物资在“信息科建档 -> 耗材科/设备科主库入库 -> 按需分发至二级库/高值仓 -> 科室人员签收 -> 临床消耗 -> 财务科审核”中**各个用户的流转关系与操作轨迹**。
- **CRUD 逻辑**：
  - **增**：业务流转自动埋点写入 + 信息科管理员人工补录异常审计日志（记录单据号、物资编码、源科室/源用户、目标科室/目标用户、流转动作、变更数量、时间戳）。
  - **删**：信息科系统管理员删除无效测试日志或执行定期归档清理。
  - **改**：管理员或审计员对流转日志添加核查备注、修正异常标记状态（`正常` / `待复核` / `已整改`）。
  - **查**：按业务单号、操作用户、源/目标科室、耗材 UDI 码、时间范围进行全链路流转穿透查询。

### 2.7 统计查询与单据打印中心
- **统计查询**：全院主库与各二级库库存总览、普通耗材 vs 高值耗材消耗金额对比、各科室月度耗材领用排行榜、近效期与呆滞物资统计报表（供财务科、设备科、耗材科、信息科多维穿透查看）。
- **单据打印**：内置标准化医院单据打印引擎（包含：主库入库单、主库按需分发调拨单、高值耗材一物一码追溯单、二级库申领单、财务科室结算汇总单），自带标准表格、条码展示区与“制单人/科室管理员/领用人/财务审核”四联签字栏。

## 3. 五大智能体（LangGraph + MCP + Chroma RAG + MySQL + Coze）与新业务精准映射

1. **智能体 1：产品字典归类与主库入库资质审查智能体（服务：耗材科/设备科管理员）**
   - 调用 MCP 查询【产品字典表】与注册证效期，结合 Chroma RAG（《医疗器械分类目录与验收标准》），自动辅助判定产品归属主科室（耗材科/设备科）、区分普通/高值分类，并在入库时拦截过期资质与临期批次。
2. **智能体 2：主库普通耗材智能按需分发调拨智能体（服务：耗材科/设备科管理员）**
   - 调用 MCP 对比【主库库存表】与各临床【二级库库存表】，结合 Chroma RAG（院内定数包补货与 FEFO 近效期先出规则），自动计算各二级库缺口，一键在数据库生成“主库向二级库/高值仓按需分发单”。
3. **智能体 3：二级库自然语言申领与耗材规范问答智能体（服务：临床二级库人员）**
   - 二级库人员通过对话提出耗材需求或询问器械使用规范，智能体通过 Chroma RAG 检索手术/诊疗耗材配包标准与说明书，通过 MCP 核验主库余量并自动写入【二级库申领单】。
4. **智能体 4：高值耗材一物一码与用户流转日志全链路溯源智能体（服务：信息科/设备科，支持对接 Coze）**
   - 调用 MCP 穿透查询【高值耗材表】与【全流程业务流转日志表】，还原“主库管理员 -> 分发员 -> 二级库接收员 -> 临床使用”的完整用户流转图谱，结合 RAG 不良事件法规自动锁定问题批次。
5. **智能体 5：多科室耗材统计精算与财务流转审计智能体（服务：财务科/信息科管理员）**
   - 调用 MCP 聚合查询【统计报表数据】与【全流程日志表】，结合 Chroma RAG（医院财务耗占比控制与内控审计制度），自动分析各科室耗材消耗异常、核查跨用户流转合规性并生成财务分析报告。

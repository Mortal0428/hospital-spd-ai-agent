### 2.1 数据库 ORM 映射与 `comment` 注释强制规范（新增架构约束）
1. **禁止散乱手写裸 SQL 建表**：统一使用 **SQLAlchemy 2.0 声明式 ORM 模型（`DeclarativeBase`、`Mapped`、`mapped_column`）** 将 Python 实体类直接映射到 MySQL 8.0 数据库，配合迁移机制实现一键建表、字段平滑修改与跨环境无缝迁移。
2. **表级与字段级 100% `comment` 覆盖铁律**：
   - **表级注释**：每个 ORM Model 必须声明 `__table_args__ = {"comment": "表名中文业务说明与流转定位"}`；
   - **字段级注释**：每个 `mapped_column(...)` 必须显式传入 `comment="字段中文名 + 业务含义 + 枚举值说明"`（例如：`mapped_column(String(32), nullable=False, comment="主库房归口主科室编码: CONSUMABLE_DEPT-耗材科主库, EQUIP_DEPT-设备科主库")`）。
3. **赋能大模型 MCP 检索**：由于 MySQL 表与字段具备完整的 `comment` 元数据，当 5 个智能体通过 MCP 数据库工具查询 Schema 时，可直接读取 `comment` 精准理解业务语义，彻底消除大模型 SQL 幻觉。

## 三、 已确定的三级人员角色与 PM 六大深度业务规则（核心业务基线）

### 3.1 三级人员权限划分
1. **系统管理员（信息科人员 `sys_admin` —— 最大权限）**：管理全院科室与人员账号、监管并执行【全流程业务链路日志】的增删改查、维护全局配置与智能体监控。
2. **科室管理员（主库房与职能管理科室 `dept_manager`：耗材科、设备科、财务科）**：
   - **耗材科 / 设备科**：维护【产品字典】（主科室归口 + 耗材分类）；管理【普通耗材管理（主库全部物资总仓）】并**按需分发给临床二级库或转入高值耗材仓库**；管理【高值耗材管理（高值专仓）】；审批二级库申领单；打印出入库与分发单据。
   - **财务科**：核对出入库与分发单据、核算各科室耗材成本、执行多维**统计查询**、月度结算审核与打印财务报表。
3. **科室人员（临床二级库人员 `secondary_user`：手术室、骨科、心内科、检验科等）**：管理本科室【二级库】，向主库发起申领、签收主库按需分发的物资、登记科室日常消耗与患者高值耗材扫码核销、打印科室领用单。

### 3.2 已融入完善的 PM 六大深度业务规则
1. **规则一：主科室归口专管与申领自动分流机制（耗材科 vs 设备科）**
   - 【产品字典】中每项物资唯一绑定“归属主库房主科室”（`耗材科主库` 或 `设备科主库`）及“耗材分类”（`普通耗材` / `高值耗材` / `设备配件`）。
   - 临床二级库发起申领时，按物资归口主科室定向路由，做到“谁主管、谁审批、谁发料”。
2. **规则二：主库总仓统管与“由量到码”分拨转换机制**
   - 全院物资采购统一先入【主库总仓】（按“批次 + 数量”登记总账）。
   - **按需分发至【临床二级库】**：针对普通耗材，按“批次 + 数量”直接调拨出库；
   - **按需分发至【高值耗材仓库】**：针对高值植入/介入耗材，转入高值专仓时触发**“批次拆包赋码（一物一码激活）”**，每个单品生成独立的 UDI 唯一序列号记录，后续全程按单品唯一码追踪至患者。
3. **规则三：“三流合一”两阶段财务记账法则**
   - **第一阶段（移库不计费）**：主库向二级库或高值仓按需分发时，仅发生院内库房位置转移，不计入临床科室消耗成本；
   - **第二阶段（消耗即结算）**：临床二级库登记“日常领用消耗”或高值耗材完成“绑定患者扫码核销”时，正式触发财务科的科室耗材成本记账。
4. **规则四：逆向业务回路与效期硬风控（ORM 状态枚举预留）**
   - **效期硬拦截与 FEFO**：过期批次自动锁定为 `EXPIRED` 禁止分发与核销；主库分发默认按 **FEFO（近效期先出）** 排序推荐批次；
   - **逆向回路支持**：ORM 模型在前期即预留 `二级库拒收退回`、`二级库向主库退库`、`过期破损报损` 状态枚举，确保后期扩展无需破坏性改表。
5. **规则五：全流程业务链路日志“6W 物权责任交接契约”**
   - 每一条全流程日志均完整记录：①物资与批次/UDI码（What）、②8大标准业务动作节点（Which Action）、③交出方科室与操作人（From）、④接收方科室与责任人（To）、⑤变动数量与变动前后库存快照（How Much）、⑥关联单据号与审计状态（Audit Status）。
6. **规则六：医院标准 5 类法定单据打印规范**
   - 统一支持《主库入库单》、《主库按需分发调拨单》、《高值耗材一物一码核销单》、《临床二级库申领/退库单》、《财务科月度科室耗材结算单》标准格式打印，内置票头条码、批次效期明细表及票尾**【制单人 / 主库科室主管 / 二级库领用人 / 财务科复核】四联签字栏**。

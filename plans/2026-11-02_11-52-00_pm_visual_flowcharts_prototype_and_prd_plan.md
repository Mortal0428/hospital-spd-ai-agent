## 1. 核心评估指标

### 1.1 可行性与把握度评估
- **把握度**：98%
- **潜在技术风险与对策**：
  - 风险点 1：直接运行 `edu-pm-workflow` 的默认安装脚本会在项目根目录散落 `.agents/`、`.handoff/`、`启动原型导出服务.bat` 等大量杂乱文件，违反本项目《四大物理目录隔离规范》。
  - 对策 1：吸收 `edu-pm-workflow` 的核心规范（标准章节顺序、范围块、跨页规则表、直角线性连接线、零文字重叠、交互原型联动），将所有可视化 HTML 产物统一收敛于 `docs/design/` 目录下，保持项目根目录 100% 纯净。
  - 风险点 2：流程图节点过多可能导致文字挤压重叠。
  - 对策 2：采用模块化分栏画布设计，每个智能体的节点流程图独立成卡，使用清晰的结构化 SVG/CSS 直角流程图，显式标注每个节点的：`[节点名称]`、`[节点作用]`、`[调用的 MCP 数据库工具 / Chroma RAG 工具]` 与 `[路由分支条件]`。

### 1.2 存量功能与三方体验影响分析
- **存量功能保护（零回归）**：完全增量创建于 `docs/design/` 与 `tests/`，对既有 `CLAUDE.md`、`AGENTS.md`、`SKILL.md` 及 `docs/*.md` 零破坏。
- **三方体验协同**：
  - **UX（用户体验）**：在真正编写 Vue3/FastAPI 代码前，您可以直接在浏览器中点击交互原型、切换角色、查看打印单据样式与智能体流程图，随时针对视觉和业务细节提出修改，成本极低。
  - **DX（开发者体验）**：后续开发 `frontend/` 与 `backend/` 时，直接照着定型的交互原型与流程图 1:1 还原即可，彻底消除返工。
  - **AX（AI 代理体验）**：直接产出最终提交要求中的硬性指标——**“画出每个智能体的流程图，每个节点的作用要标注清楚，在录制视频时讲解”**。

### 1.3 Playwright 自动化回环测试与截图验证方案
- **验证脚本**：`tests/harness/verify_pm_design.js`
- **验证路径与断言条件**：

## 2. 技术与 UI 细节规范

### 2.1 `docs/design/spd_business_and_agent_flowcharts.html`（业务全景与 5 大智能体节点流程图）
- **画布 1：全院三级人员与物资全链路流转总图**
  - 展示【信息科管理员】、【耗材科/设备科主库管理员】、【高值耗材专仓】、【临床科室二级库人员】、【财务科管理员】之间的单据流、实物流、财务记账流与 6W 日志埋点。
- **画布 2 ~ 6：5 大业务智能体 LangGraph 节点详细流程图（视频讲解专用视图）**
  - **Agent 01**：产品字典智能归类与主库入库合规审查智能体（5 个节点详解）
  - **Agent 02**：主库全部物资智能按需分发与补货调拨智能体（4 个节点详解）
  - **Agent 03**：临床二级库自然语言申领与耗材规范问答智能体（4 个节点详解）
  - **Agent 04**：高值耗材一物一码与跨用户流转日志全链路溯源智能体（含原生 LangGraph + Coze 双模节点详解）
  - **Agent 05**：多科室耗材统计精算与财务流转合规审计智能体（4 个节点详解）

### 2.2 `docs/design/spd_interactive_prototype.html`（高保真可点击全业务交互原型）
- **顶部栏**：支持一键切换当前登录角色体验权限变化（信息科系统管理员 / 耗材科管理员 / 设备科管理员 / 财务科管理员 / 骨科二级库护士）、支持亮暗主题无缝切换。
- **左侧导航与主工作区（7 大核心视图全部可点击切换）**：
  1. **产品字典管理**：左侧展示“主库房归口主科室（耗材科主库/设备科主库）+ 耗材分类（普通耗材/高值耗材/设备配件）”树，右侧展示字典 CRUD 表格。
  2. **普通耗材管理（主库总仓 + 按需分发）**：展示主库全部物资批次库存、效期预警标签，提供“新建按需分发调拨单（发往临床二级库 / 转入高值耗材专仓）”弹窗交互。
  3. **高值耗材管理（一物一码专仓）**：展示主库分拨拆包后的 UDI 唯一序列号单品台账，提供“绑定患者住院号扫码核销”交互。
  4. **二级库管理（临床科室库房）**：展示临床科室二级库库存、定数包预警、“向主库发起申领/退库”及“签收主库分发单”交互。
  5. **全流程业务链路日志（6W 物权交接台账）**：展示跨用户流转关系时间轴（交出科室/交出人 -> 动作节点 -> 接收科室/接收人 -> 前后库存快照）与日志 CRUD。
  6. **统计查询与单据打印中心**：展示财务与科室统计看板，并提供**《主库按需分发调拨单》与《高值耗材核销单》医院标准四联签字栏打印预览弹窗**。
  7. **5 大智能体协同工作台**：支持选择切换 5 个智能体，左侧对话与参数输入，右侧实时高亮展示当前执行的 LangGraph 节点、MCP 数据库工具调用结果与 Chroma RAG 法规引用。

### 2.3 图标与样式契约
- 全域 100% 禁用 Emoji，所有图标均采用标准 `viewBox="0 0 24 24"` 语义化内联矢量 `<svg>`；
- 100% 采用 CSS 变量体系（`--bg-primary`、`--text-primary`、`--border-color`、`--accent-color` 等），原生支持深浅色模式一键切换。

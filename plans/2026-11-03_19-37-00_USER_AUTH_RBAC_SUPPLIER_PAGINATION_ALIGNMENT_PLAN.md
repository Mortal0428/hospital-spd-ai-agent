## 3. 全景业务流转路径（端到端 11 大核心业务节点）

```
[节点 1: 产品字典管理] (耗材科/设备科)
    │ 录入器械分类、注册证号、医保编码、主科室归口(耗材/设备)及存储类型(普耗主库/高值专柜)
    ▼
[节点 2: 供应商准入资质提报与审核] (供应商门户 + 医院管理端)
    │ 外部供应商注册并上传《医疗器械经营许可证》等"三证一书"，绑定目标医院
    │ 医院管理端审核通过后生效(QUAL_APPROVED)，若未审或过期则硬拦截供销权限
    ▼
[节点 3: 采购计划生成与审批下发] (临床科室 / 主库备货)
    │ 临床请领超限或主库触发安全库存低水位，生成采购计划单(PLAN_SUBMITTED)
    │ 耗材科主管审核通过(DEPT_APPROVED)，正式向对应中标供应商下达采购订单
    ▼
[节点 4: 外部供应商接单、拣货与二次确认发货] (供应商协同门户)
    │ 供应商进入订单池点击【确认接单】(PICKING 拣货配货中)
    │ 仓库完成拣货，录入生产批号、有效期至、灭菌批号与配送随货单号
    │ 供应商执行【二次确认发货】(DELIVERING 派送在途)
    ▼
[节点 5: 普通耗材主库验收入库与状态联动闭环] (耗材科主库)
    │ 供应商发货瞬间，系统后端自动生成医院端《待验收入库单 (PENDING_CONFIRM)》
    │ 主库库管员核对实物与随货单，执行【实物验收合格并入库】
    │ 主库总仓库存增加，生成 6W 入库流转日志，同时联动将供应商端订单标记为【已完成 (COMPLETED)】
    ▼
[节点 6: 临床二级库定数申领与主库按需分发调拨] (临床科室 -> 主库)
    │ 临床二级库护士提交物资申领单(待审核)
    │ 主库库管员受理审批，系统自动按照 FEFO (近效期先出) 原则匹配拣货批次
    │ 主库执行分发出库，生成调拨在途单(已审核出库)
    ▼
[节点 7: 临床二级库实物接收与科室出库发料] (临床二级库)
    │ 临床科室护士核对实物并执行【接收实物入库】
    │ 二级库科室在库库存增加，生成 6W 接收日志
    │ 科室护士针对治疗/患者执行【手动发料出库】或直接消耗记账
    ▼
[节点 8: 高值耗材专仓一物一码 (UDI) 全生命周期管控] (专柜/手术室)
    │ 临床提报高值备货申请 -> 主库审核下发 -> 二级库专柜接收上架
    │ 手术治疗中使用：扫码枪扫描 UDI 专属二维码，核验批号，绑定脱敏患者住院号核销
    │ 若未用、破损或过期：提报高值退货出库，提交即不可逆物理锁定
    ▼
[节点 9: 全域独立盘点与三级库平账引擎] (全院各级库房)
    │ 主库独立盘点 / 高值专仓盘点 / 二级库独立盘点
    │ 创建盘点计划 -> 自动拉取在库底表 -> 录入实盘清点数据
    │ 盲盘比对计算盈亏差异 -> 主管审批调账平账，更新在库库存与底表
    ▼
[节点 10: 财务精算成本核算与 6W 全生命周期审计追溯] (财务科/信息科)
    │ 财务科精算多科室月度耗材成本、高值核销记账与资金沉淀，输出精算报告
    │ 审计人员输入任意 UDI 码或单据号，穿透追溯 6W 动态流转日志(Who, When, Where, What, Why, Which)
    ▼
[节点 11: 全院人员动态鉴权与 15 业务模块 × 8 动作细粒度 RBAC 矩阵] (系统管理员)
    │ 系统管理员维护人事档案与角色，动态分配全院用户
    │ 15 大业务模块 × 8 项原子动作独立开关，支持整行一键赋权/清空
```

## 4. 技术规范与详细设计

### 4.1 供应商全生命周期协同与系统联调技术方案

1. **角色物理边界与权限隔离**：
   - 供应商账号角色标识为 `supplier_user`；
   - 供应商绝对不具备院内任何仓库的查看、申领、调拨或患者隐私查看权；
   - 供应商专属视图为 `SupplierPurchaseView.vue`（采购订单协同、发货派送、经营资质提报）。
2. **资质准入硬拦截机制 (GSP 规范)**：
   - 数据模型：`SpdSupplierAndPurchaseOrder.qual_audit_status`（`QUAL_PENDING` / `QUAL_APPROVED` / `QUAL_REJECTED`）；
   - 拦截逻辑：在 `execute_supplier_purchase_flow` 中，当 `qual_audit_status != "QUAL_APPROVED"` 时，禁止调用接单或发货 API，直接抛出 HTTP 403 错误并向前端返回明细原因；
   - 前端体验：若供应商未完善资质，登录后顶部展示全幅警示条，点击呼出资质提报弹窗（录入社会统一信用代码、许可证编号、有效截止日期、上传资质扫描件凭证、选择合作医院）。
3. **采供 4 阶段状态机协同闭环**：
   - `待接单 (PLAN_SUBMITTED / DEPT_APPROVED)`：医院端下达，供应商端在待办列表查看明细；
   - `拣货中 (PICKING)`：供应商点击接单，进入配货准备；
   - `派送在途 (DELIVERING)`：供应商录入真实生产批号、有效期至、发票号与承运单号，二次确认提交发货；后端自动在 `SpdInboundAndOutboundOrder` 中生成 `INB-SUP-{order_no}` 待验收入库单；
   - `单据完成 (COMPLETED / HOSP_INBOUND_CREATED)`：医院主库验收人员执行入库后，双向同步标记订单完成。
4. **单据增删改查、详情穿透与四联单打印**：
   - 列表支持条件查询与分页；
   - 点击任一订单号或明细行，呼出《采供四联凭证全景详情穿透弹窗》：
     - 表头信息：订单号、供应商、医院归口科室、制单时间、审核状态；
     - 明细列表：产品编码、品名规格、采购数量、拣货批号、有效期至、单价、总金额；
     - 6W 流转时间轴：提报人 -> 审批人 -> 接单人 -> 发货人 -> 入库人时间节点；
     - 四联签字栏：采供方经办人、医院质检员、仓管员签名与盖章栏；
     - 操作按键：支持触发浏览器标准打印或导出四联凭证。

## 5. 针对性扩充与优化建议（产品经理、医疗顾问与供应商视角）

1. **【医疗器械监管顾问 (GSP) 视角】**：
   - **资质临期 30 天自动黄标预警**：在供应商资质档案中，当经营许可证有效截止日期与当前时间差小于 30 天时，自动标注“即将到期”黄色警告；已过期时强制标红并硬拦截订单下发，避免医院面临药监局飞检合规风险。
   - **批号效期一票到底双向核对**：供应商发货时填写的生产批号与有效期，自动锁死并透传至医院验收入库单，医院库管员验收时可拍照上传随货同行单照片进行图文留痕。
2. **【医疗产品经理 (PM) 视角】**：
   - **单据详情穿透与全景时间轴**：所有涉及跨角色交接的单据，均应支持点击单号查看全景弹窗，包含上下游前置单据引用号与 6W 审计时间轴，让业务链条无断点。
   - **个人主页快捷操作与常用书签**：在个人主页中为不同角色提供其最常用的 3 个功能快捷直达入口（如库管员的验收入库、护士的申领、供应商的接单）。
3. **【外部供应商 (SCM) 视角】**：
   - **待办订单分类与批量接单**：区分常规采购订单与急诊急救绿色通道订单（急救订单置顶并标红闪烁）；
   - **对账单月度汇总导出**：在已入库完成订单中，提供按月度聚合生成供销对账单并导出 Excel，便于双方财务月末对账开票。
